# Student Performance Analyzer

A beginner-friendly Python project that reads student marks from a CSV file and creates a simple performance report.

## Features

- Reads student records from `students.csv`
- Calculates total and average marks
- Assigns a grade based on the average
- Checks whether each student passed all subjects
- Displays the class average and top performer
- Validates that marks are between 0 and 100

## Technologies

- Python 3
- CSV file handling
- Functions and conditional logic

## Project structure

```text
student-performance-analyzer/

```

## How to run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

No third-party packages are required.

## Sample data

The included `students.csv` file contains example student marks. You can edit it or add more rows using the same columns: `name`, `maths`, `science`, and `english`.

## Learning outcomes

This project demonstrates basic Python programming, CSV file handling, functions, loops, conditional statements, input validation, and simple data analysis.
